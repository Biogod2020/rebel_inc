## 真实浏览器输入验收

用 Python Playwright 驱动系统 Chromium，通过真实鼠标、地图坐标、键盘与文件控件操作。浏览器读取的模型状态仅用于观察和选择合法指令；未改写游戏资源、战力、民心或胜利条件。

一次完整「灰烬山脊 / 民政专员 / 标准 / 种子 58421」战役：**117 次建设、政策、招募、行军、疏散等界面命令**，另有逐周按键和界面导航。第 **167 周** 正常获胜，稳定人口 **90.99%**，人口民心 **90.30%**，累计居民伤亡 **27**。这局先通过实际界面执行了一套开局，与上方纯模型策略比较并非完全相同的命令序列，因此结果不同。通过的是「稳定至少 85% 且武装低于 5，连续 8 周」的重建路线，不是和平进程达到 100% 的路线。

验证暂停和实时推进、工程和招募、地图选区与行军、两次火山喷发、事件选择、正常终局、浏览器下载 JSON 存档、用文件输入控件导入、1280 × 800 与 390 × 844 布局、补给图层、手册开关，以及 localStorage 不可用时的明确导出提示。没有未捕获的 JavaScript 页面错误。原始摘要见 `browser-report.json`。

### 必须区分的环境限制

验收容器的浏览器策略阻止 URL 导航，因此用 `page.set_content` 注入完整的已构建单文件 HTML；只把显式测试 API 开关设为开启，游戏逻辑和美术与交付版本相同。自动保存使用显式的内存存储适配器，另外单独验证存储被拒绝的错误处理。**这里没有把真实 `file://` 导航、持久化跨浏览器会话、Safari、Firefox 或手机真机当作已通过的项目。** 离线文件没有外部资源；常规环境也可以通过本地服务器运行。

完整脚本位于 `tests/browser_smoke.py`。需要额外安装 Python Playwright 和 Chromium，它们不是游戏运行或核心测试的依赖：

```bash
python -m pip install playwright
# 安装可用的 Chromium，或指定现有浏览器的路径。
npm run build
CHROMIUM=/path/to/chromium python tests/browser_smoke.py
```

脚本输出 `artifacts/browser-report.json`、真实界面动作记录、导出存档和 13 张截图。截图包含标题、开局、部署、预警、喷发、后期、结算和响应式布局。它是可复现的界面验收，不代表真人主观试玩评分。
