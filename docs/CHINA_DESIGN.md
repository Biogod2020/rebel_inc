# 中国背景战役：设计依据与界限

核对日期：2026-10-15。我们采用中国的地方行政和产业基础设施语境，而不将现实国家冲突改成游戏关卡。2032、三省名称、前线、冲击、决策权限、时间和预算全是原创架空设定。

## 来源如何进入设计

财政部《2025年中央和地方预算执行情况与2026年中央和地方预算草案的报告》，2026-03-16：中央对地方转移支付、基层“三保”、预算绩效与债务约束，为“支持申请—拨付—用途核验”提供制度背景。游戏并未复刻具体财政制度，也不能以游戏反推真实比例或政策效果。
https://www.mof.gov.cn/zhengwuxinxi/caizhengxinwen/202603/t20260316_3985331.htm

应急管理部“国家总体应急预案”公开栏目：作为协调和保障视角的入口。我们用多部门联席桌而非万能省长表述玩家；真实军地职责与指挥权限没有按一对一映射模拟。
https://www.mem.gov.cn/fw/yjya/gjztyjya/

Torpor Games，Suzerain 3.1 “Sovereign”，2025-05-13：参考治理、外交、经济和叙事后果相互作用的设计思路。我们仅实现八组短事件与持续方案，不声称拥有其人物关系、国会或长篇叙事系统，也没有复制其素材。
https://www.torporgames.com/press-releases-new/2025/5/13/sovereign-update

Hooded Horse，Terra Invicta 官方介绍：参考把国家能力与冲突放入同一策略层的思路。没有实现其全球地缘模型、轨道力学或太空战争。
https://www.hoodedhorse.com/games/terra-invicta

ICRC，Protecting essential service personnel is a vital part of humanitarian action，2024-10-10：强调基本服务依赖设施及其运维人员的持续工作。游戏据此保留独立技术队、施工时间和安全/补给门槛，避免把修复简化为点击即刻恢复。
https://blogs.icrc.org/law-and-policy/2024/10/10/protecting-essential-service-personnel-is-a-vital-part-of-humanitarian-action/

这些材料只支撑设计动机，不是模拟校准数据或现实战争建议。所有系数、概率、门槛、事件分支都是为了游戏可玩性设定的假设。

## 实际闭环

1. 设施完好度、安全与补给决定设施有效性。供电可靠性影响服务覆盖与产出；工业/货运有效性、就业、外部压力、动员共同决定民用产出目标。
2. 产出逐周向目标收敛，并影响每四周收入。动员、预算侧重、协调方式同时产生维护开支。月度预估明确排除一次性拨款。
3. 有限/强化动员提高实际战斗倍率和补给恢复，代价是民用产出目标下降与额外支出；强化动员提高外部压力，并与当前降级操作不兼容。
4. 支持款延时发放并单次核验。核验目前检查民用支出与腐败，不评估工程的细致社会收益；这是已知简化。周转偿付总额高于到账额，未结清不能滚动借款。
5. 外压、人道协调、平民伤亡、动员选择及谈判互相反馈；停火和前线受控均是可选结局，但都不能绕过民生与生产条件。

## 主动不做的伪真实

不把居民不满转换为敌方兵源；新模式边缘增援与支持率独立。民心、稳定、民生保供分别表示信任、恢复进度和基本服务，不是一根全能的政治进度条。前线规模为抽象战斗单位，既非真实人数也非旅级编制。

“集中保供”的地方响应代价、“属地响应”的速度限制都是游戏中的可争论建模假设，不是对现实政治制度的经验断言。“三保优先”被压缩成公共服务覆盖与固定支出，并不把现实三保逐项建模。

海岸场景的外贸、保险和航运压力通过外压—产出联动及事件表达；没有船舶、港口吞吐量或独立海战。通信中心只是情报与调度节点，不含真实网络攻防。人员流离失所仍沿用原有地区需求变量，并非个体迁移/人口守恒模型。

中国战役复用两类原有地形生成器、不同种子与节点/前线位置，尚不是三套完全独立的地理生成系统。八组政治事件按固定序列重复，不具有动态议程或独立部门智能体。

## 后续值得验证，而非继续堆按钮

先用真人观察检验：玩家能否解释动员的机会成本、能否发现供电瓶颈、是否真的会选择降级路线。脚本配置全部获胜只说明可完成，提示还需检查高难度强度和优势策略。更深的政治博弈应先验证独立部门目标与执行延迟是否增加有意义的取舍，再考虑人物/派系。
