# 山河之间 · AFTERFIRE

**v0.3.0 · 现代中国背景的架空政军策略游戏。** 2032年，在一张省域军地联席协调桌上，兼顾前线防御、关键保供、产业恢复、县域公共服务、中央支持与危机降级。守住前线，也守住生活。

这是原创游戏，不是现实冲突预测或真实军事推演。地图、对手、事件和数值均为虚构；玩家聚合多个部门的决策，不对应现实任何单一职务的权限。预算是游戏点数，不是人民币。

## 直接玩

下载仓库后，用桌面浏览器打开根目录 **`index.html`**。全部代码与原创程序画面内嵌在这个文件中，没有联网素材、登录、付费服务或 API 密钥。文件预览页可能不执行脚本，应下载后在浏览器中打开。

首次建议 **江城保卫线 → 民生先行 → 宽松**。进入时暂停：先回应人口中心的民生诉求、招募机动支援，然后在「联席会 → 关键保供」申请支持并安排供电修复。按空格继续；`.` 可逐周推进。选择部队后点地图下达行军命令。

主屏保留三个指标：可用预算、协调授权、民生保供。预算下方是按当前方案预计的每月净额，不包括一次性拨款。底部仍只有五个入口；联席会分「联席方案 / 关键保供 / 长期能力」，一次只展开一个页面。

## 三场不同的省域危机

| 战役 | 核心压力 | 变化 |
| --- | --- | --- |
| 江城保卫线 | 沿江工业与县域基本生活 | 工业、电网与城市群；由地图边缘进入的前线压力 |
| 临海压力场 | 民用通商与威慑取舍 | 更高的初始外部压力、更强的压力—产出联动，不是独立海战引擎 |
| 云岭生命线 | 山地交通与跨区协同 | 不同的通道地形、关键设施布局和较弱的初始供电 |

三个中国背景战役与三个经典重建场景并存。主菜单的「经典重建模式」进入河谷、火山、走廊旧玩法；旧版存档仍按原规则运行。经典玩法说明见 [docs/CLASSIC.md](docs/CLASSIC.md)。

## 政治不是新闻弹窗，战争不是唯一答案

**军地资源占用：** 常态防御、有限动员、强化动员三选一。有限/强化动员实际提高战力和补给恢复，同时挤占民用产出、增加固定维护；强化动员持续提高外部压力，并阻止正式停火与降级联络。

**预算与执行：** 均衡预算、三保优先、产业保供有不同的持续收支与产出/服务效果；属地响应、军地协同、集中保供在施工效率、开支和地方诉求响应之间取舍。三个维度共用四周调整间隔，不能同一周全部切换；悬停按钮可查看尚未执行方案的后果。

**关键设施：** 电力、货运、工业、通信四个实际地图节点。供电影响公共服务和工业，货运/工业影响产出，通信提高情报；敌控、损坏与断供会削弱功能。每次只派一支跨区技术队，修复需要时间，安全或补给中断时暂停。

**中央支持：** 申请后四周拨付32预算；申请后24周核验新增民用支出≥24且腐败≤30。通过增加授权，未通过扣授权。两次申请至少相隔48周，不能叠加待核验申请。应急周转另有真实的游戏偿还约束：获得36、总偿还42、每月自动扣6，未结清不再借入。时间和金额均为游戏参数，不是现实制度规定。

**政治事件：** 八组、21个分支选项，涉及医院与工业用电、市县预算、动员与就业、统计核验、民用通商、平民安置、紧急采购和停火窗口。每个事件都有不需要额外预算的选项，但并不都没有代价。

**敌方与居民分开：** 中国战役的敌方兵力来自抽象边缘前线和增援规则，不由居民低支持率或不满自动生成。居民诉求影响生活恢复与授权，不等同敌对武装。接触协调是与前线武装争取局部停火，不是把村民当作敌人。

v0.2 的三条初始路线、三次局内三选一授权、限时委托、侦察、援助车队、接触协调、空运、道路补给、部队轮换与行军均保留。初始路线不可中途改换；联席方案可以按四周间隔调整。

## 什么才算赢

中国战役从第64周起，需要连续八周同时达到：民生保供≥70%、民用产出≥55%、稳定人口≥55%、敌控人口<8%，再满足下面至少一条。

- **降级与恢复：** 停火进程≥85%、外部压力≤60、敌方规模<85。
- **防御与重建：** 敌方规模<8、外部压力≤72。

仅消灭敌方并不能获胜。授权归零、外部压力≥98持续12周，或第300周仍未达标则失败。具体进度在「全局」显示。门槛是游戏平衡参数，不是对真实治理或战争的评分。

## 操作与保存

空格暂停，`1 / 2 / 3` 为 1× / 2× / 4×，`.` 推进一周；`B / U / P / M / I` 打开建设、部队、联席会、委托和全局。`Esc` 收起详情，`H` 手册，`S` 保存。滚轮缩放、拖动地图、`0` 复位。

成功操作后和每四周自动保存，切到后台自动暂停。手册中可以下载/导入 JSON 存档。新行动覆盖自动存档，先导出需要保留的进度。浏览器限制本地存储时会显示导出提示，也可用下面的本地服务器。音效默认关闭。

## 开发与复现

TypeScript + Canvas 2D，Node.js 22+；唯一 npm 开发依赖为锁定的 TypeScript 5.8.3。运行游戏不需要 npm。

```bash
npm ci --ignore-scripts
npm start                         # http://127.0.0.1:4173
npm run check
npm test                          # 核心、经典、v2及省域战役回归
npm run build                     # 更新根目录及 dist/index.html
npm run balance                   # 经典场景脚本比较
npm run balance:china             # 54局省域配置 + 6局对照
```

`npm start` 只在启动时构建，不含热更新。`HOST` / `PORT` 可改地址和端口，默认只监听本机。`src/theatre.ts` 管省域规则，`src/campaign.ts` 管局内路线/授权/外勤，`src/simulation.ts` 管逐周模拟；渲染和界面与模拟分离。CI 检查单文件构建与源代码一致。

详细验收：[docs/TESTING.md](docs/TESTING.md)。设计边界和现实/游戏来源：[docs/CHINA_DESIGN.md](docs/CHINA_DESIGN.md)。

## 边界

这是一款可以完整游玩的策略原型，不是商业级现代战争模拟器。没有真实领导人、真实前线或武器参数；没有独立海空作战、导弹拦截、网络攻击、多人、原生安装包和完整人物关系系统。三个中国战役仍共享二维地区引擎。来源用于提炼取舍，不证明游戏数值符合现实。

程序化地图、建筑、图标与提示音均原创，不复制 Rebel Inc. 或参考游戏的代码/地图/美术，不分发字体。脚本通关与浏览器测试不等于真人乐趣或难度验证。
