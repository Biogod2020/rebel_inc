# 烬土 · AFTERFIRE

**v0.2.0 · 地图优先的原创重建策略游戏。** 在冲突与灾害之间修复道路、恢复生活、保护居民，并决定如何兑现自己的承诺。完全离线，中文界面，单文件运行。

这一版重新设计了界面、地形绘制和局内选择，不是在旧面板上增加更多按钮：默认只有三个资源指标、一个行动提示和底部指令栏。点击地图才展开地区详情；工程先显示三项建议，完整目录按需展开。

## 直接开始

下载仓库，使用桌面浏览器打开根目录 **`index.html`**。没有运行时依赖、外部素材、登录或 API 密钥。文件预览服务可能不执行脚本，应使用真正的浏览器打开下载后的文件。

首次建议：**河谷重建 → 民生先行**；难度和治理者在「难度与高级设置」里。开局暂停，点击人口中心，回应它的一项诉求，再开始招募部队。按空格继续，选中部队后点击目的地区域即可移动。资金每四周入账，工程、训练与行军都需要时间。

## 三条路线，不是三个加成名称

| 本局路线 | 优势 | 代价与玩法 |
| --- | --- | --- |
| 民生先行 | 民生工程费用 −10% | 部队维护 +15%；围绕人口中心与工程扩散组织重建 |
| 生命走廊 | 部队、运输队移动时间 −20% | 工程费用 +10%；修路、护送运输、恢复沿线地区 |
| 地方共治 | 地方调解费用 −25%、正式和谈进度 +25% | 联合支援队招募 +$4；将有限驻军与调解、复员结合 |

每局开局选择一条，不可中途切换。第 16、56、104 周各获得一次三选一授权，九种授权包括乡村合作社、山间电台、流动诊疗、社区演练和停火观察员。组合只影响本局，不需要刷永久属性。

委托提供建设、道路、运输、调解、连续保护和火山救援六类可选目标。每批选一份，完成后获得预算；错过承诺会小幅扣除声望，但委托不是必须完成的主线。救援委托以喷发前为硬截止，不能事后补交。

## 不只有工程与进攻

点击地区可以发起四类外勤，最多两组同时执行：侦察需等待情报返回；援助运输沿实际路线出发，可能受阻、损失物资，或寻找替代路线；地方调解需要足够情报与可控的武装规模；紧急空运绕开地面阻断，支持补给与疏散。成功效果在任务结束时兑现，不是点击即到账。

运输不依赖一条装饰性动画线。部队可以护送路段；撤回只退回 30% 预算且保留冷却。改变路线从车队当前地区重新出发，不瞬移、不重置货物损失。获得「停火观察员」后，调解形成 24 周地方停火；主动突击会结束当地停火。

三个场景是「河谷重建」「灰烬山脊」「断裂走廊」。火山有预警、疏散、关闭道路与灾后安置；建设、补给、民心和安全相互影响。武装并非唯一的问题：只控制领土不会自动取得胜利。

## 控制与胜利

空格暂停；`1 / 2 / 3` 对应 1× / 2× / 4×；`.` 推进一周。`B / U / P / M / I` 分别打开建设、部队、施政、委托和全局。`Esc` 收起详情或可关闭的弹窗。滚轮缩放、拖动平移，`0` 复位；右侧图层按钮展开自然、民心、补给和情报视图。

连续八周满足以下任一条件即获胜：至少 70% 人口稳定、和平进程完成且武装规模低于 65；或至少 85% 人口稳定、武装规模低于 5。声望归零，或到第 360 周仍未完成任务则失败。稳定比例按人口加权。具体条件和声望变化在「全局」中查看。

每四周与成功操作后自动保存；切到后台自动暂停。`S` 保存，右上角手册或 `H` 打开存档导入导出。新行动会覆盖自动存档，保留旧进度前先导出。支持旧版存档迁移；浏览器限制本地存储时会显示导出提示。音效默认关闭，可在手册开启。

## 开发

使用 **TypeScript + Canvas 2D**，不依赖大型 3D 引擎。模拟规则与渲染分离，开发依赖仅有锁定版本的 TypeScript 5.8.3；Node.js 22 或更高版本。

```bash
npm ci --ignore-scripts
npm start                 # 本地 http://127.0.0.1:4173
npm run check             # 严格类型检查
npm test                  # 核心、回归与组合测试
npm run balance           # 54 组路线比较 + 9 组对照
npm run build             # 更新根目录和 dist/ 的离线 index.html
```

`npm start` 构建一次后启动本地服务器，不含热更新。更改源码后重新构建、刷新。`HOST`、`PORT` 可改监听配置，默认只监听本机。CI 检查源码与已提交的离线 HTML 一致。

```text
src/model.ts       类型、数据、参数、确定性随机数
src/world.ts       地区生成、邻接、路径、补给图
src/campaign.ts    路线、授权、外勤、委托、停火及其存档验证
src/simulation.ts  逐周经济、施工、军事、灾害、胜负与命令验证
src/render.ts      原创程序地景、聚落、运输动画、地图交互
src/ui.ts          地图优先界面、上下文操作、弹窗、输入、保存
src/main.ts        固定步长时钟；渲染帧率不改变模拟结果
src/style.css      桌面浮动控件与窄屏底部详情布局
```
